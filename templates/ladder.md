# 主体性阶梯

同一级完成两次、且最近一次 SUDS ≤ 40 就升级。完成记录由 `anchor.py ladder done` 追加。

- [ ] **L01**｜关系外｜点餐或买东西时说一次「不要 X」，不解释原因。
- [ ] **L02**｜关系外｜对朋友说一次自己的偏好：「我更想去 A」，不先问对方想去哪。
- [ ] **L03**｜关系外｜同事请我做不想做、也不在职责内的事，说「这次我不行」，不编理由。
- [ ] **L04**｜关系内｜说一次具体的喜好：「我喜欢你……」或「我不喜欢……」。
- [ ] **L05**｜关系内｜提一个具体的小要求：「下次……可以……吗？」说完等回答，不收回。
- [ ] **L06**｜关系内｜对一件不想做的小事说「我不想」，不找外部理由。
